## 2025-05-18 - Accessible Search Input with Clear Button Pattern
**Learning:** Pairing an embedded search clear button with conditional right-padding (`pr-10` vs `pr-4`) prevents text truncation or overlap with the clear action, while an explicit screen-reader label ensures assistive tech announces the input purpose properly.
**Action:** Always provide a screen-reader accessible label alongside input placeholders, and pair interior action buttons with responsive padding and focus-visible rings.
