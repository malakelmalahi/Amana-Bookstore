## 2025-05-21 - [Inline Feedback for Cart Actions]
**Learning:** Asynchronous inline feedback (loading and success states) is significantly more pleasant and less disruptive than immediate page redirects for cart additions, as it maintains the user's browsing context and provides clear confirmation of the action.
**Action:** Prioritize inline button state transitions for cart-related actions instead of redirects to improve flow and user delight.
