## 2026-04-21 - [Accessibility] Missing Skip to Main Content Link
**Learning:** Keyboard users have to tab through the entire navigation menu (Home, My Cart with potential count badge) on every page load before reaching the main content. This is a common accessibility barrier that can be solved with a skip link.
**Action:** Implement a "Skip to main content" link as the first focusable element in the layout, targeting a `main-content` ID on the main element.
