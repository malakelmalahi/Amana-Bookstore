# Palette's Journal - Amana Bookstore UX/Accessibility Learnings

## 2026-04-23 - [Skip to Main Content Pattern]
**Learning:** For apps with fixed navigation bars and multiple focusable elements (like the 'Home' and 'My Cart' links), keyboard users have to tab through the navigation on every page load. A 'Skip to main content' link is a critical accessibility standard that is often overlooked in early-stage Next.js projects.
**Action:** Always implement a 'Skip to main content' link in the root layout when building or enhancing Next.js applications with global navigation.
