## 2025-05-15 - [Accessible Search Inputs with Context and Clear Controls]
**Learning:** Adding a screen-reader-only (`sr-only`) label and a decorative magnifying glass icon at the start of a search field provides immediate visual and screen-reader context. When adding a search-clearing control inside the text input, the input should dynamically add right padding to prevent search text overlapping with the clear button, and the clear button itself must have an explicit `aria-label` and handle `focus-visible` ring styles for keyboard navigation.
**Action:** Always provide `pl-10` padding-left on input fields with a decorative start icon, conditionally adjust `pr-10` padding-right if an absolute-positioned close button is rendered, and ensure clear controls are accessible non-form `type="button"` elements.
