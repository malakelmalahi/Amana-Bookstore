## 2025-05-15 - [Search UX Enhancements]
**Learning:** Combining visual feedback (icons), functional improvements (clear button), and accessibility (aria-live, sr-only labels) in a single component like a search input significantly elevates the perceived quality of the interface.
**Action:** Always consider the "full package" for search inputs: icon for context, clear button for convenience, and proper ARIA support for accessibility.
