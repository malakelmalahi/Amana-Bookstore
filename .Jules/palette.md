## 2025-10-27 - Accessible Dynamic Feedback in Cart Interfaces
**Learning:** When updating dynamic text values like item quantities or price totals in the UI, wrapping the elements in `aria-live="polite"` and `aria-atomic="true"` ensures assistive technologies announce the new values immediately without interrupting the user. Additionally, icon-only buttons or buttons with simple text like "+"/"-" require descriptive `aria-label` attributes to provide context. Using a hidden label with Tailwind's `sr-only` class is also effective for providing textual context to currency values.
**Action:** Always apply `aria-live` and `aria-atomic` to dynamic UI updates and ensure all interactive elements have descriptive ARIA labels, especially in task-oriented views like shopping carts.
