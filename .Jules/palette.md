## 2025-05-15 - Accessibility Enhancements for Navigation and Cart
**Learning:** Screen reader users benefit significantly from descriptive labels on interactive elements that lack text (like icon buttons) or when visual state (like a cart badge) needs to be communicated semantically. Additionally, a "Skip to main content" link is a fundamental accessibility feature for keyboard-only users to bypass repetitive navigation. Using `aria-label` on the parent link and `aria-hidden` on the visual badge prevents redundant announcements while providing clear status updates.
**Action:** Always include a skip-to-content link in the root layout and ensure all buttons, especially those with minimal text or icons, have descriptive ARIA labels that provide context. Use `aria-label` to combine visible text and state information for complex components like navigation links with badges.
