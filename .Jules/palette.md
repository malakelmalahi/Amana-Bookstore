## 2025-02-18 - Detail Page Add-to-Cart Feedback Pattern
**Learning:** Forcing immediate user redirection to the cart page upon clicking "Add to Cart" on a detail page disrupts the shopping experience and browsing momentum. Transitioning this behavior to asynchronous, inline status feedback ("Adding...", "Added!") with screen-reader friendly dynamic announcements maintains context and increases user satisfaction, mirroring the catalog grid/list card behavior.
**Action:** When designing detail pages for transactional applications, prioritize persistent inline state validation and loading/success transitions over disruptive redirection flow. Use `aria-live="polite"` on the trigger element to immediately notify assistive tech users of visual text mutations without disrupting their focus.
