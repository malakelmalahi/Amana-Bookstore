## 2025-02-15 - Accessible Search Input and Live Counter Enhancements
**Learning:** Purely text-based search inputs relying solely on visual placeholders are inaccessible to screen reader users. Additionally, when lists dynamically filter or change count based on search or filtering, screen reader users are left unaware unless the result count is explicitly wrapped in `aria-live="polite"` with `aria-atomic="true"`. To prevent text overlap on absolute-positioned clear buttons, the input needs dynamic right padding.
**Action:** Always wrap search input count texts in an ARIA-live polite region to announce result set updates. Provide a screen-reader-only `<label>` linked to the input via `id`, a decorative magnifying glass icon at the start, and an accessible 'Clear' button at the end with dynamic right padding (`pr-10` vs `pr-4`) on the input field.
