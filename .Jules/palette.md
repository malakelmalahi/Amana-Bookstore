## 2026-05-05 - Asynchronous Inline Cart Feedback
**Learning:** Prioritizing asynchronous inline feedback over page redirects (like moving to a cart page after adding an item) maintains user browsing context and reduces friction. Consistent feedback patterns (loading/success states) across different views (grid, list, detail) reinforce the application's predictability.
**Action:** Always implement asynchronous inline feedback for cart actions and avoid disruptive redirects unless explicitly requested by the user flow.
