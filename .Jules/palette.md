## 2025-05-15 - [Accessibility Improvements]
**Learning:** Icon-only buttons and navigation links with dynamic badges require explicit ARIA labels to provide context for screen reader users. The "Skip to main content" link is a fundamental but often overlooked requirement for keyboard accessibility in web applications.
**Action:** Always include a "Skip to main content" link in the root layout and ensure all interactive elements have descriptive labels, especially when they only contain icons or numbers.
