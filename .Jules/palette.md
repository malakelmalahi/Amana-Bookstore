## 2025-05-18 - [Dynamic Cart Item Quantity and Accessibility Support]
**Learning:** For interactive list views (like a Shopping Cart), simple textual values like quantity updates or total prices can confuse assistive technologies unless they are wrapped in an assertive live region. Dynamic item quantities and totals need explicit `aria-live="polite"` and `aria-atomic="true"` properties. Additionally, icon-only buttons or subtle math controls (like `+`, `-`, and `Remove` buttons) need descriptive `aria-label` context linking back to the specific item title, and raw values need `<span className="sr-only">` headers to announce what the numbers represent.
**Action:** When updating dynamic text values like item quantities or price totals in the UI (e.g., `CartItem.tsx`), always wrap the element in `aria-live="polite"` and `aria-atomic="true"`, use screen-reader-only labels (`sr-only`) rather than `aria-label` on non-interactive elements, and ensure all buttons have descriptive item-linked `aria-label` tags.
