## 2025-05-18 - [Accessible and Responsive Search Inputs with Clear Action]
**Learning:** Adding an absolute-positioned 'Clear' action inside a text input requires careful layout orchestration: dynamic right padding (e.g., `pr-10` when active, `pr-4` when empty) is essential to prevent search queries from visually overlapping the button. Furthermore, form-only placeholders violate basic screen reader accessibility; we must use a screen-reader-only `<label>` with a matching `htmlFor`/`id` pair. Decorative icons must remain hidden (`aria-hidden="true"`), and interactive icon buttons require distinct `focus-visible` focus rings for robust keyboard navigation.
**Action:** Always wrap search input enhancements in relative containers, apply dynamic horizontal paddings corresponding to absolute icons/actions, and pair with `.sr-only` labels and visible keyboard focus rings.
