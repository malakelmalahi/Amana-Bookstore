## 2025-07-21 - Client-Side Custom Event Synchronization for Next.js Cart Badges
**Learning:** In a Next.js App Router application where components are rendered dynamically or partially hydrated, sharing client-only state (like a localStorage-backed shopping cart) across disconnected components (such as an overview page's book grid and a layout's header navbar) can be achieved reliably without global state managers by using lightweight native CustomEvents. Dispatching a custom event on window ensures that the Navbar updates immediately without needing a page reload.
**Action:** Next time when implementing decentralized cart interactions, use window.dispatchEvent(new CustomEvent('cartUpdated')) to synchronize local storage-backed UI states seamlessly and instantly across components.
